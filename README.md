# PSD再合成診断 v0.2.2

## 修正点

v0.2.1 では PSD合成済みの元画像を `psd.canvas.transferToImageBitmap()` でUIへ渡したため、Canvasが空になりました。その後の再合成比較が空の参照画像に対して実行され、平均アルファ誤差が約255となる重大な診断誤りがありました。v0.2.2 は元画像を別Canvasへコピーしてから転送し、比較元 `psd.canvas` を保持します。

## 検証手順

既存の GitHub Pages リポジトリ直下の `index.html` と `psd-worker.js` を両方置き換えてから、ブラウザを強制再読み込みしてください。各PSDを再度読み込み、「元の表示状態で再合成」を実行し、結果と「詳細診断JSON保存」の新しいファイルを確認してください。今回は **全レイヤー強制表示ではなく元の表示状態** で実行したJSONが重要です。

この版は比較の基準を修正するもので、マスク・クリッピング等の再合成エンジンはまだ暫定実装のままです。
