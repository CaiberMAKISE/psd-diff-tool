# PSD差分一括生成ツール v0.3.1 — Phase 3.1

## 配備
既存のGitHub Pagesリポジトリ直下に `index.html` と `psd-worker.js` を両方上書きします。
ページを更新し、`UI v0.3.1 / Worker v0.3.1` と表示されることを確認してください。

## 試し方
1. `ember_ic.psd` または `wisleah_ic.psd` をブラウザで読み込んでください。
2. 「分類ツリー」で土台になるレイヤー・グループを「固定（土台）」に設定してください。初期状態で未分類の要素は表示しません。
3. 「目」「口」「眉」などのフォルダには自動でカテゴリ割当候補を入れていますが、必ず確認・調整してください。フォルダ分類を子要素が継承します。
4. カテゴリ選択UIで表示する差分を選択してください。排他カテゴリは候補があれば常に1個、複数カテゴリは0〜最大数を選択します。
5. 複数のレイヤーをまとめて差分にするフォルダには「🔒一括」をチェックしてください。その下のレイヤーは元PSDの表示状態を引き継ぎ、子要素ごとに「元の表示／表示／非表示」を指定できます。
6. 「プレビュー更新」を押すと、分類に従う単一の画像を描画します。
7. 分類設定を保存したい場合は「分類設定JSON保存」を押してください。

## この版の範囲
- 固定・未分類・分類カテゴリ、親子継承、子の明示的な分類上書き
- 排他カテゴリと複数カテゴリ（最大選択数付き）
- フォルダを単一差分とするロック、ロック内部の表示上書き
- 単一組み合わせプレビュー、分類設定JSONの保存
- 旧v0.2.7の元表示再合成と差分診断機能を維持

## 既知の制約
- カテゴリ自動割当はフォルダ名 `目` `口` `眉` `眉毛` の完全一致のみ。固定（土台）はユーザーが指定する必要があります。
- この版ではカテゴリ間の相互除外・全組み合わせ列挙・画像一括出力・ZIP出力・設定JSON読み込みは未実装です。
- 「分類設定JSON保存」は設定の書き出しのみで、再読み込み機能は次の段階です。
- ロック内部で子の分類を変更しても、ロック中は差分の列挙には使われません。ロック解除すると子の分類指定が再び有効になります。
- マスク・クリッピング・複雑なグループ効果の合成精度はPSDごとに異なり、完成品としての完全一致を保証しません。
- 外部ライブラリ ag-psd は初回にCDNから読み込みます。PSDデータは外部送信しません。

## 確認してほしい内容
- `ember_ic.psd` で `!立ち絵` を固定、`目`・`口`・`眉毛` をカテゴリとして1つずつ選択したとき、表情が表示されること。
- `wisleah_ic.psd` で描画に必要な土台グループを固定にした上で、口のフォルダをロックして単一差分として選べること。
- 通常の「元の表示状態で再合成」を押した場合、v0.2.7から大きく劣化しないこと。
