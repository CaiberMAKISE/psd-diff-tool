# PSD差分生成ツール v0.2.4 — 合成機能診断

## 更新方法
GitHub Pagesリポジトリ直下の `index.html` と `psd-worker.js` をこの版で置き換えます。更新後、Ctrl+Shift+Rで再読み込みしてください。

## 変更内容
- v0.2.3で検証した正しい描画順（PSDツリーを配列の最後から走査）を標準化しました。
- 8bitラスターマスクの簡易ピクセル適用を追加しました。マスクの位置・既定色・相対座標・濃度を考慮します。
- 同一グループ内のクリッピングベースのαを利用した簡易クリッピングを追加しました。
- マスク・クリッピングをそれぞれON/OFFできます。
- 「4条件を連続比較してJSON保存」: なし / マスクのみ / クリッピングのみ / 両方、の平均誤差を比較できます。
- 描画診断JSONに、適用したマスク・クリッピング件数、孤立クリッピング、マスク画像なしの数を追加しました。

## 重要な制限
これは完成版の合成エンジンではありません。通過グループと背後のレイヤーとの相互作用、クリッピングベースのグループをまたぐ処理、ベクターマスク、realMask、マスクのぼかし、特殊なブレンドモードやレイヤー効果は正確には再現できません。ON/OFFの比較によって誤差が増える場合もあり、その結果から修正対象を絞ります。

## 検証
1. `ember_ic.psd` を読み込み「元の表示状態で再合成」を実行し、前回の平均誤差約0.087と近いか確認します。
2. `wisleah_ic.psd` を読み込み「4条件を連続比較してJSON保存」を実行します。
3. ダウンロードした `wisleah_ic-features-comparison.json` をチャットへ添付してください。
4. 必要であればマスクとクリッピングを両方有効にし「詳細診断JSON保存」を実行してください。

ファイルはブラウザ内でのみ読み込み、アップロードしません。PSD解析にはCDN版 `ag-psd@31.0.3` を使うためネット接続が必要です。
