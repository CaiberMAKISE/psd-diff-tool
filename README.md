# PSD差分ツール — 再合成の調査版 v0.2

前回のv0.1の `index.html` と `psd-worker.js` を、このZIPの2ファイルで置き換えてください。GitHub PagesのURLは同一のままで構いません。キャッシュが残る場合は Ctrl+Shift+R で強制再読み込みしてください。

## 操作

1. PSDを読み込みます。今回から各レイヤー画像もデコードするため、v0.1より時間とメモリを使用します。
2. 元の合成済み画像とツリーが表示されたら「レイヤーから再合成して比較」を押します。
3. 再合成画像、差分画像、不一致ピクセル数、警告を確認します。
4. エラーがある場合はブラウザの開発者ツールのConsoleと画面の文言を共有してください。

## 大切な制限

**この版は合成エンジンの診断用で、出力用ではありません。** 通常のレイヤーと一部のCanvas合成モードの動作を確認します。マスク、クリッピング、通過グループの詳細、グループマスク、PSD色管理、調整レイヤー、レイヤー効果は未対応または暫定です。レイヤーごとの警告を表示します。画像が異なることは仕様上あり得ます。PSDのオリジナル画像はGitHubへアップロードしません。

`ag-psd@31.0.3` のCDN読み込みはネットワークアクセスが必要です。
