# PSD差分ツール — Phase 2.1 描画原因診断

GitHub Pagesに公開している前回の `index.html` と `psd-worker.js` を、今回のZIP内の同名ファイルで上書きしてください。ブラウザでCtrl+Shift+Rを使って再読込します。新しいリポジトリは不要です。

## 検証手順

1. PSDを開き、「元の表示状態で再合成」を押します。
2. 「描画診断」の `実描画`、`元から非表示`、`画像なし`、`描画されなかったレイヤー` を確認します。
3. 「詳細診断JSON保存」を押し、保存された `*-render-diagnostic.json` をこのチャットへ添付してください。
4. 必要に応じて「診断：全レイヤー強制表示」を押し、顔のパーツが復帰するか確認してください。このモードは本来のPSDの出力結果とは一致しません。診断用です。
5. 可能なら、前回表示異常の出た `wisleah_ic.psd` と今回の `ember_ic.psd` の両方で検証してください。

## 診断項目

- レイヤーごとの元の表示状態と、非表示祖先の有無
- 各レイヤーの画像Canvas取得有無・実描画の有無・未描画理由
- レイヤー境界とCanvasサイズ、合成モード・不透明度
- クリッピング・マスク・レイヤー効果の有無
- 不透明度を考慮したRGB誤差とアルファ誤差

## 制限とプライバシー

本版は原因究明用であり、差分出力用ではありません。特別な合成・通過グループ・マスク・クリッピング等の完全再現はまだ行っていません。ファイルはブラウザ内で処理されますが、解析ライブラリのCDN読み込みには通信が必要です。診断JSONにはPSD内のレイヤー名等が含まれるため、公開リポジトリにアップロードしないでください。

### 既知の解釈上の注意

`ember_ic-diagnostic.json` は `ember_ic.psd`（300×300）の**構造情報のみ**です。前回の画像スクリーンショットは別ファイル `wisleah_ic.psd` でした。両者を同じPSDの記録として扱わないでください。
