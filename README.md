# PSD差分ツール v0.2.7 — 領域別誤差分析

## 更新方法
既存GitHub Pagesリポジトリの `index.html` と `psd-worker.js` を両方上書きしてください。ページ更新後に UI / Worker とも v0.2.7 であることを確認します。

## 検証
1. `wisleah_ic.psd` をブラウザで読み込みます。
2. マスク・クリッピング・通過グループをすべてONにします。
3. 「元の表示状態で再合成」を実行します。
4. 再合成画像、差分画像、領域別ヒートマップを確認します。
5. 「詳細診断JSON保存」から `wisleah_ic-render-diagnostic.json` を保存します。

## 新しい診断
- 領域サイズは30×30px（画像端は自動調整）
- 誤差閾値0/2/8/16/32/64/128を超えるピクセル数
- 最大誤差の座標
- 上位20領域の座標・平均最大チャンネル誤差・閾値超過数
- 上位10領域が占める誤差の割合
- 30px単位の誤差ヒートマップ

注意：誤差閾値は各ピクセルのRGBAの最大チャンネル差で測定します。完全一致でない画素は広く存在するため、誤差>16/64を重点的に確認してください。画像は引き続きブラウザ内で処理されます。
