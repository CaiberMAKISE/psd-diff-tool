# PSD差分ツール v0.3.3 — 分類・表示対象診断

## 更新
GitHub Pages のルートへ `index.html` と `psd-worker.js` を上書きし、ブラウザをハードリロードします。UI / Worker v0.3.3を確認してください。

## 今回の変更
- 分類により実際にONとなるレイヤー一覧を画面に表示
- 固定指定された上位フォルダを経由し、未分類の表情差分が固定表示となる可能性を警告
- 分類設定変更時にも診断を更新
- 合成エンジン自体はv0.3.2のまま維持

## 確認方法
PSDを読み込み、分類ツリーと「実際に表示するレイヤー一覧」を確認。上位フォルダを固定にした場合、子の分類を明示的にカテゴリへ変更する必要があります。
