# PSD差分ツール v0.4.8 — Workerバージョン修正

## 修正内容
- UIから読み込むWorkerのURLを `psd-worker.js?v=0.4.8` に修正。旧v0.4.6 Workerがキャッシュから利用される問題を防ぎます。
- 画面のWorker状態表示を、PSD未読込／起動中／起動失敗／起動成功に区別。
- v0.4.7の90pxサムネイル、拡大表示、選択状態保存、組み合わせ生成、合成診断を保持。

## アップロード
ZIP内の `index.html` と `psd-worker.js` の2ファイルを、GitHubリポジトリの公開ルートへ同時に上書きしてください。ZIPそのものをアップロードするのではなく2ファイルを配置します。

## 動作確認
1. ハードリロード後、UI v0.4.8を確認。PSD読込前の「Worker未起動」は正常。
2. PSDを読み込むと「Worker起動中」を経て「Worker v0.4.8」と表示される。
3. 組み合わせ生成後、90pxサムネイルと虫眼鏡での拡大画像が表示される。
4. 起動失敗なら画面のエラーを報告してください。

## 備考
ブラウザのキャッシュが残る場合は Ctrl+Shift+R を試してください。
