# PSD再合成検証 v0.2.6

既存GitHub Pagesのリポジトリ直下で `index.html` と `psd-worker.js` を上書きしてください。両バージョンが v0.2.6 と表示されていることを確認してください。

## 変更内容
- `pass through` グループのうち、不透明度100%、グループマスクなし、クリッピングなしの場合に子レイヤーを背景へ直接合成します。
- それ以外の通過グループは従来の隔離合成にフォールバックし、警告を出します。
- `color dodge` 等のスペース入り合成モード名に対応します。
- `visibleMaskCandidates` / `visibleClipCandidates` の未初期化を修正。
- 単独レイヤー診断における子配列走査順を修正。

## 検証
- `ember_ic.psd`: 「元の表示状態で再合成」で平均誤差が約0.0866となること。
- `wisleah_ic.psd`: 「6条件を連続比較してJSON保存」を実行し、JSONを送付。
- 最初の4件は通過グループ旧方式でマスク・クリッピングON/OFFを切り替え、5件目は両方ON＋通過グループ直接合成、6件目は両方OFF＋通過グループ直接合成です。
- 通過グループ直接合成は、グループ単位の不透明度、マスク、クリッピング境界を完全再現するものではありません。
- `color dodge` もCanvas 2DとPSDの計算方式の差が残る可能性があります。
- 再合成画像が完全一致する保証はありません。
