# PSD差分一括生成ツール — Phase 2.3 (診断版)

GitHub Pages の既存リポジトリ直下に `index.html` と `psd-worker.js` を上書きしてください。ブラウザを強制再読み込みします。PSDはアップロードされず、ブラウザ内で処理されます。ライブラリの読み込みにはインターネット接続が必要です。

## 今回の追加
- 元PSD順（下→上）と、逆順（上→下）の再合成を切り替え。
- 「両順序を連続比較」でそれぞれの診断JSONを記録し、自動で `*-order-comparison.json` を保存。
- 各レイヤーツリー行の「単独」ボタンでレイヤーやフォルダ内容を単独表示。
- 実描画レイヤーの順序を診断JSON（drawSequence / drawOrder）と画面で確認。

## 手順
1. `ember_ic.psd` を読み込んで「両順序を連続比較」を押します。
2. ダウンロードされる `ember_ic-order-comparison.json` をこのチャットに添付します。
3. 可能なら `目/*目瞑る_涙` と `!立ち絵` の「単独」表示を確認します。
4. 同様に `wisleah_ic.psd` でも比較します（複雑なPSDのため結果はまだ大きく不一致になりえます）。

## 注意
- 逆順合成は原因切り分け専用です。正規のPSD描画順への変更を意味しません。
- 単独表示は親フォルダのマスク・クリッピング・グループ不透明度などを再現していません。
- マスク、クリッピング、通過グループなどはまだ未完成の診断版です。生成物を正式な出力には使用しないでください。
