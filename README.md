# PSD差分ツール v0.4.1 — 組み合わせ列挙の初期版

GitHub Pages のルートに `index.html` と `psd-worker.js` を上書きしてください。

## 追加内容
- 現在の分類設定から組み合わせ候補を列挙。
- 排他カテゴリは1つ選択、複数選択カテゴリは 0〜上限個で組み合わせます。
- 先頭N件を一覧表示し、各行から現在の単一プレビューへ適用可能。
- 組み合わせ一覧を JSON で保存可能。

## 確認手順
1. `UI v0.4.1 / Worker v0.4.1` を確認。
2. `ember_ic.psd` または `wisleah_ic.psd` を読み込む。
3. 分類設定を行った後、「組み合わせ生成」を押す。
4. 推定総数・一覧件数が表示されることを確認。
5. 一覧の「適用してプレビュー」で、指定した組み合わせが単一プレビューへ反映されることを確認。
6. `-combinations.json` を保存し、件数や内容を確認。

## 制限
- まだサムネイル一括生成・不要組み合わせのチェック・ZIP出力は未実装。
- 多数の候補がある場合は列挙上限で打ち切ります。
