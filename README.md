# PSD差分ツール v0.4.4（診断拡張）

v0.4.3 をベースに、組み合わせ列挙・分類・PNG出力・4条件診断を維持しています。

## 変更内容
- UIとWorkerをv0.4.4に統一し、キャッシュ回避パラメータも更新。
- 対象レイヤーの不透明度を 0% / 25% / 50% / 75% / 100% へ試験的に上書き可能。
- 元の不透明度と「親フォルダマスクなし」も含む7画像を連続生成。
- 既存の4条件診断も維持し、PNG個別保存、診断JSONへ適用したoverride情報を保存。
- **本バージョンではPSDのデフォルト描画式を意図的に変更していません。** CanvasのglobalAlphaでの不透明度指定と、合成後の背景補間は通常のsource-over/multiply条件では数学的に等価であり、根拠なく置き換えても精度改善を保証できないためです。

## 手順
1. index.html と psd-worker.js をGitHub Pagesへ上書き。
2. UI/Worker v0.4.4 を確認。
3. wisleah_ic_test.psdと前回と同じ分類設定で、影（r/1/2/6/0）を選択。
4. 「不透明度比較（7条件）」を押し、7つのPNGと診断JSONを保存。
5. クリスタ出力PNGと見比べ、最も近い不透明度／マスク条件を確認。

## 注意
- 7条件のうち「親マスクなし」は診断専用です。本来のPSD合成の代替には使いません。
- 診断JSONの元PSD合成画像との誤差は、今回の分類選択と元PSD保存時の表示状態が異なる場合、クリスタ出力との誤差を示しません。
