# PSD差分ツール v0.4.6

GitHub Pages のリポジトリ直下へ `index.html` と `psd-worker.js` を上書きします。

## 追加機能
- 組み合わせ一覧のサムネイルは **90×90px** に縮小、カード表示もコンパクト化。
- 虫眼鏡（🔍）から原寸の画像を Worker で再描画して表示。サムネイル自体のクリックは選択の切り替えのみ。
- 出力対象の選択／除外を JSON に保存、再読み込み。
- Worker URL を v0.4.6 に明示し、キャッシュ混在を回避。

## 検証
1. ページ上の `UI v0.4.6 / Worker v0.4.6` を確認。
2. PSD読み込み→分類JSON読み込み→組み合わせ生成。
3. 90pxのサムネイルが見えること、画像クリックで選択が反転することを確認。
4. 虫眼鏡から原寸プレビューが出ることを確認。
5. 一部候補を除外→選択状態JSON保存→選択を変更→JSON読込で元の状態に戻るか確認。

## 留意
- 一括PNG/WebP/ZIP出力は次段階です。
- 既存の v0.4.5 の合成エンジンは維持しています。
- 選択状態JSONは同じPSD・同じ候補集合に再適用してください。
