# PSD差分ツール v0.3.4

## 修正

- 通常グループの描画再帰処理でレイヤーIDの親パスを引き継ぐよう修正しました。分類設定の可視性マップは `r/1/0` などの完全なIDを使用しているため、従来の `r/0` のような誤参照を排除します。
- HTML内のWorkerキャッシュ更新クエリを `v=0.3.4` に修正しました。
- それ以外の再合成アルゴリズム・分類設定は変更していません。

## 手順

1. `index.html` と `psd-worker.js` をGitHub Pages公開リポジトリへ上書きします。
2. `UI v0.3.4 / Worker v0.3.4` を確認します。
3. `ember_ic.psd` を読み込み、`!立ち絵` を固定、「目・口・眉毛」から各1つ、「表情」から必要な選択をし、プレビューを更新します。
4. 選択肢を変えると画像のその部位だけが切り替わるかを確認します。

注意：元の `!立ち絵` レイヤー自体に既に顔パーツが描かれている場合、その部分も合成されます。表示対象一覧はレイヤーを示すもので、個々のレイヤー内部の絵柄は示しません。
