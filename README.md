# PSD差分ツール v0.3.5 — PNG比較用出力

v0.3.4 の分類・描画エンジンを継承し、ブラウザ内の原寸Canvasから PNG を書き出します。PSDそのものはアップロードされません。

## 追加機能

- **PSD合成済みPNG保存**：読み込んだPSDに格納された合成済み画像をPNG保存。ファイル名 `<PSD名>-merged.png`。
- **プレビューPNG保存**：最後に成功した分類プレビューをPNG保存。ファイル名 `<PSD名>-preview.png`。
- PSDを読み直した際・分類を変更した際・プレビュー生成中は古いプレビューの保存を無効化します。
- 出力は canvas.toBlob('image/png')。元PSDの幅・高さを保持し、市松模様を含まず透過を維持します。ブラウザのPNGエンコーダによるカラーメタデータはブラウザに依存します。

## GitHub Pagesへの反映

`index.html` と `psd-worker.js` を上書き後、キャッシュを無視して再読み込みし、UI/Workerともに `v0.3.5` を確認してください。

## 比較にあたって

同一レイヤー表示状態のクリスタ出力PNGと `<PSD名>-preview.png` を比較してください。`-merged.png` はPSD保存時の可視状態を表すため、分類プレビューの表示状態が異なる場合に直接一致しません。

色空間メタデータや実表示に起因する違いと、実際のRGB数値の違いを区別するため、可能なら出力3枚をそのまま添付してください。
