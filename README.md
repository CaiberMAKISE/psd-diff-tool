# PSD差分ツール v0.4.2 — レイヤー合成診断

GitHub Pagesのルートに `index.html` と `psd-worker.js` を上書きしてください。

## 継続する機能
- v0.4.1の組み合わせ列挙、一覧、適用、JSON保存
- 分類設定とロック、単一プレビュー、原寸PNG保存

## 追加
対象レイヤーを選択し「4条件で描画」を押すと、現在の組み合わせ設定でA:通常、B:対象なし、C:単独、D:対象だけnormal、の4画像を生成します。各画像のPNG保存と、診断JSON保存に対応します。

## 検証
1. `UI v0.4.2 / Worker v0.4.2` を確認。
2. `wisleah_ic.psd` を読み、該当する影の乗算レイヤーを選択。
3. 比較したい組み合わせを適用し、プレビュー更新。
4. 対象レイヤーを選択し、4条件で描画。
5. 4画像のPNGと診断JSONを保存してチャットに添付。

注意：Cの単独表示は背後の画像がないため、乗算が通常表示と同じになる場合があります。元PSD保存時とは違う差分構成の場合、基準画像との差分数値は参考値です。
