# PSD差分ツール v0.4.7 — ギャラリー描画停止修正

## 修正
- v0.4.6の `pumpGallery` で不正な `querySelector` 文字列が使われており、初回サムネイル描画で例外が発生していた問題を修正。
- 描画要求の例外を捕捉し、ギャラリーの待機状態を解除。画像の描画が失敗しても連続描画が停止しにくくなるようにした。
- 拡大描画時のWorkerエラーは拡大画面に表示する。
- v0.4.6の90pxサムネイル、原寸拡大、組み合わせ選択、選択JSON保存と読込を維持。
- Worker・UIの表示バージョンをv0.4.7へ更新。

## GitHub Pages更新
`index.html` と `psd-worker.js` を上書きし、UI/Worker v0.4.7を確認。PSDはGitHubにアップロードしない。

## 動作確認
1. PSD読込→分類設定読込→組み合わせ生成。
2. 一覧を表示すると90px画像が順次表示されること。
3. 虫眼鏡から原寸表示できること。
4. 以前正常だった単一プレビューも維持されていること。
