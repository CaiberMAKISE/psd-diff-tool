# PSD差分ツール v0.4.3 — マスク付き通過グループの修正

## 更新手順
GitHub Pages リポジトリのルートに `index.html` と `psd-worker.js` を上書きします。UI/Workerともv0.4.3であることを確認してください。

## 修正
- マスク付き pass through グループを透明な独立Canvasに隔離せず、実際の背景に対して描画するよう修正。
- グループ描画前後の画像をマスクの濃度とグループ不透明度で補間。RGBはpremultiplied alphaで計算し、透明領域でも補間結果が不正にならないように対応。
- レイヤー診断の「D: 通常合成」が「A: 元の乗算」と異なるかを確認できるようにしました。
- 組み合わせ列挙、分類設定、フォルダロック、プレビューPNG出力は維持。

## 検証
1. 問題の `wisleah_ic_test.psd` と以前の分類設定を読み込み、`影` (r/1/2/6/0) を選択。
2. 4条件診断を実行し、AとDが異なるか、Aがクリスタ出力PNGに近づいたか確認。
3. A,B,C,DのPNGと診断JSONを共有。
4. `ember_ic.psd` の基本再合成が従来と同程度に正常であることも確認。

## 未対応・注意
- `realMask` / `vectorMask` / グループを跨ぐ複雑なクリッピングは依然として未対応。
- PSD内の合成済み画像との平均誤差は、分類による表示状態が異なる場合には正しい品質比較ではありません。同じ選択状態のクリスタPNGとの直接比較を優先してください。
- Canvasのブレンド演算とクリスタの出力が完全に一致する保証はありません。
