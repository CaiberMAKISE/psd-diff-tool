# PSD差分ツール v0.3.2（Phase 3.1 ホットフィックス）

## 修正内容
- 重大: HTMLがWorkerを `psd-worker.js?v=0.2.7` で読み込んでいたため、キャッシュされた旧Workerでは分類プレビューの完了イベントが識別できず「生成中…」のままになる問題を修正しました。`?v=0.3.2` に変更。
- UI/Workerバージョン一致をプレビュー開始前に確認します。
- 描画エラー、予期しない旧形式の応答、メッセージ受信エラーをプレビュー領域に表示し、ボタンを復帰します。
- 90秒を超える場合、無期限に「生成中…」とせずエラーを表示します（Workerそのものは中断しません）。

## 配備
GitHub Pagesリポジトリ直下の `index.html` と `psd-worker.js` を両方上書きしてください。反映後、ハードリロードして `UI v0.3.2 / Worker v0.3.2` を確認してください。

## 検証
1. PSDを読み込む。
2. 固定土台と目・口・眉のカテゴリを設定する。
3. 「プレビュー更新」を押す。
4. 完了すると単一画像と描画情報が表示されます。異常の場合は「生成失敗」と詳細エラーが表示されるため、その文面を共有してください。
