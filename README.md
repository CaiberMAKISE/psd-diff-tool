# PSD差分一括生成ツール — 読み込み検証 v0.1

これは**完成品ではありません**。PSDの読み込み、レイヤー階層・元の合成済み画像の確認に限定した初期検証版です。

## GitHub Pages公開

1. GitHubで新しいリポジトリ（例: `psd-diff-tool`）を作成。
2. `index.html` と `psd-worker.js` をリポジトリ直下にアップロードし、コミット。
3. Settings → Pages → Build and deployment → Sourceを `Deploy from a branch` に設定。
4. Branchを `main`、フォルダを `/ (root)` に設定して保存。
5. 表示されたPagesのURLへアクセス。公開URLは通常 `https://ユーザー名.github.io/psd-diff-tool/`。
6. `wisleah_ic.psd` 等をブラウザで読み込み、ツリー・元画像が正しいか確認。

**PSDファイル本体はリポジトリにアップロードしないでください。** サイトでファイルを選択した後も、処理はブラウザ内です。

## 注意事項

- 初回アクセス時には外部CDNから `ag-psd@31.0.3` を取得します。オフラインでは動作しません。
- Web Worker を使用するため、ローカルでの `file://` 直接起動は動かない場合があります。GitHub Pages上で検証してください。
- 同名レイヤーは階層位置に基づくIDで区別します。
- サムネイル合成・差分分類・再合成・ZIP出力は今後の版で実装します。
- 合成済み画像はPSDに保存された画像であり、レイヤーから再合成したものではありません。
- 不正に大きいPSDの対策を含め、実運用にはさらに安全対策が必要です。
