# PSD差分ツール v0.4.9 — 一括ZIP出力（初期版）

- 既存の選択・組み合わせ列挙・90pxサムネイル・拡大・診断は維持。
- 選択済みの組み合わせだけを順次原寸レンダリングしZIP出力。
- PNG、WebP（ブラウザ標準エンコーダーで品質1.0、厳密な可逆WebPではない）、両形式に対応。
- ファイル名接頭辞、区切り文字、連番開始番号（0〜999999999）、最低桁数（1〜9）を指定可能。
- 出力対象が除外されていれば詰めて採番し、両形式では同じ番号を使用。
- ZIP32方式の無圧縮格納（PNG/WebPは形式として圧縮済み）。ブラウザメモリ内で保持するため数GB級の出力は不可。
- 対象は「一覧化した組み合わせ」の中の選択済み全件。列挙上限に達した場合、列挙していない候補は出力しない。

## 検証
1. index.html と psd-worker.js をGitHub Pagesに上書き。
2. PSD読み込み後 UI/Worker v0.4.9 を確認。
3. 組み合わせを生成、数件だけ選択。
4. 接頭辞 `wisleah_ic`、開始番号 `5`、最低桁数 `2` でPNG出力。`wisleah_ic05.png`から開始することをZIP内で確認。
5. PNG+WebPも実行し、同番号で2形式出力されることを確認。
6. PNGがPSD原寸・透過を維持することを確認。

既知の制限：WebP lossless未対応、ファイルをZIP Blobとしてメモリ保持、ZIP64未対応、出力中にPSDや分類を再読込しないでください。
