# PSD差分ツール v0.3.6 — 分類設定JSONの読み込みとロック検証

GitHub Pagesのルートに `index.html` と `psd-worker.js` を上書きしてください。PSD本体はアップロード不要です。

## 今回の追加
- 分類設定JSONを再読み込み（同じPSDファイル名に限る）。カテゴリ、分類、ロック、内部表示状態、選択差分を復元します。
- 未知のレイヤーIDを安全に無視します。設定を反映した後は必ずプレビューを更新してください。
- ロックされたフォルダ内部の子レイヤーを「表示」に明示変更した際、祖先フォルダを構造的に開いて描画対象へ到達できるよう改善。
- ロック数を画面に表示。

## 確認手順
1. `ember_ic.psd` を読み込み、以前の分類JSONを読み込んでプレビュー更新。以前と同じ出力か確認。
2. `wisleah_ic.psd` を読み込み、土台を固定にし、任意の差分フォルダをカテゴリに分類してロックする。
3. ロック済みフォルダを選択してプレビューし、フォルダ内部の表示を変更→再プレビュー。画像に差が出るか確認。
4. 設定JSON保存→ページ再読み込み→同PSD読み込み→設定JSON読込→プレビュー更新。設定が復元されるか確認。

## 制限
- カテゴリ間相互除外、全組み合わせ列挙、ZIP出力は未実装。
- フォルダロック内部の表示状態はPSDの元の可視状態を基本にし、明示表示/非表示で上書きします。
- 大規模で特殊なPSDの再現性は別途検証が必要です。
